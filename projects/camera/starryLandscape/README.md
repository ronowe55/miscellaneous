# Star Trail Timelapse Generator

星景写真の連番JPEGから、**地上風景を固定したまま、星だけを累積比較明合成したタイムラプス動画**を生成するPythonスクリプトです。

複数の星景写真を1枚ずつ累積比較明合成し、星の軌跡が徐々に伸びていくようなタイムラプスを作成します。

また、山や地上風景については現在のフレームを使用することで、地上部分が時間経過によって明るくなっていくことを抑えます。

---

## 完成イメージ

通常の星景タイムラプスでは、各フレームをそのまま動画にすると星が点として移動します。

このスクリプトでは、

```text
フレーム1
   ↓
フレーム1 + フレーム2
   ↓
フレーム1 + フレーム2 + フレーム3
   ↓
...
```

という形で空の部分を累積比較明合成します。
その結果、

```text
星
●
 ↓
●────
 ↓
●────────
 ↓
●────────────
```

のように星の軌跡が徐々に伸びていくタイムラプスを作成できます。
地上部分については累積せず、各フレームの地上画像を使用します。

### 作例の処理内容

- 入力画像：Sony α7R IIIで撮影した星景写真
- 空：過去フレームまで累積比較明合成

## 入力画像

基本的に、以下のような連番JPEGを想定しています。

```text
DSC08986.jpg
DSC08987.jpg
DSC08988.jpg
DSC08989.jpg
...
DSC09136.jpg
```

ファイル名は、`DSC` + `5桁の連番` + `.jpg` を前提としています。  
例: `DSC08986.jpg`

### 入力画像の条件

現在のスクリプトでは、以下の画像サイズを前提としています。

`5304 × 7952 pixels`

これはSony α7R IIIで撮影した画像を前提とした設定です。  
異なるカメラや異なる解像度の画像を使用する場合は、スクリプト内の画像サイズ設定を変更する必要があります。

### 撮影条件について

このスクリプトは、基本的に以下のような星景タイムラプスを想定しています。

- カメラを固定（三脚などを使用、撮影中に構図が変化しない）
- 焦点距離を固定
- ピントを固定
- 絞りを固定
- シャッタースピードを固定
- ISOを固定
- ホワイトバランスを固定
- 撮影間隔をできるだけ一定にする

特に、撮影中に露出設定が変化すると、フレームごとの明るさが変化し、タイムラプスにちらつきが発生する可能性があります。

## 使い方

### 1. リポジトリを取得

```bash
git clone https://github.com/ronowe55/miscellaneous.git
cd miscellaneous/projects/camera/starryLandscape
```

### 2. pyenvと仮想環境のセットアップ

pyenvを使用してPython 3.12環境を用意し、プロジェクト専用の仮想環境を作成・有効化します。

```bash
# 指定のPythonバージョンをインストール（未導入の場合）
pyenv install 3.12.0

# ディレクトリローカルのPythonバージョンを設定
pyenv local 3.12.0

# 仮想環境を作成 (.venv)
python -m venv .venv

# 仮想環境を有効化 (macOS / Linux)
source .venv/bin/activate

# (参考) Windowsの場合:
# .venv\Scripts\activate
```

### 3. Pythonライブラリのインストール

`requirements.txt` を使用して必要な依存ライブラリ（Pillow, NumPyなど）を一括インストールします。

```bash
pip install -r requirements.txt
```

### 4. スクリプトを実行

```bash
python make_startrail.py
```

### 5. JPEGディレクトリを指定

スクリプト起動後、JPEG画像が保存されているディレクトリを入力します。  
例:
```text
JPEG_DIR > /Users/username/Pictures/star_photos
```

JPEG画像はGitリポジトリ内に置く必要はありません。  
例えば、

```text
my-startrail-tool/
├── make_startrail.py
├── requirements.txt
├── README.md
└── .gitignore
```

とし、写真は別の場所に保存できます。

```text
/Users/username/Pictures/star_photos/
├── DSC08986.jpg
├── DSC08987.jpg
├── ...
└── DSC09136.jpg
```

### 6. START番号を入力

例:
```text
START > 8986
```

### 7. END番号を入力

例:
```text
END > 9136
```

この場合、`9136 - 8986 + 1 = 151` となり、151枚が処理対象になります。  
処理枚数はスクリプトが自動計算します。

### 8. 出力先を指定

出力先を入力できます。
```text
OUTPUT_DIR >
```

何も入力せずEnterを押した場合は、JPEGディレクトリ内に `startrail_output/` が自動的に作成されます。

## 処理フェーズ

このスクリプトは、処理を複数のフェーズに分けています。  
各フェーズの終了後に確認を行い、問題があればそこで処理を中断できます。

### Phase 1 - 元画像確認
指定されたSTART～ENDの画像が存在するか確認します。  
また、画像サイズが想定サイズと一致するか確認します。

### Phase 2 - 山の基準画像作成
最初の51枚を使用して、各画素の中央値を計算します。  
これにより、時間によって移動する星をある程度除去し、`mountain_reference.jpg` を作成します。  
この画像を確認して、山や地上風景が適切に残っていることを確認してください。

### Phase 3 - 山マスク作成
`mountain_reference.jpg` をもとに、空と地上を分離するマスクを作成します。  
出力: `mountain_mask_preview.jpg`

マスクでは、
- 白 = 空
- 黒 = 山・地上

となります。このマスクを使用して、
- 空 → 累積比較明合成
- 地上 → 現在のフレーム

という処理を行います。

### Phase 4 - 5枚テスト
本番処理の前に、最初の5枚だけを使用してテストします。  
出力: `test_5frame_mountain.jpg`

ここで必ず以下を確認してください。
- 星が比較明合成されている
- 星の軌跡が伸びている
- 山が固定されている
- 地上が不自然に明るくなっていない
- 山の輪郭に不自然な線が入っていない
- 空と地上の境界が自然

問題がある場合は、ここで処理を中断してください。

### Phase 5 - 連番JPEG生成
問題がなければ、すべてのフレームを処理します。  
出力:
```text
star_frames/
├── frame_001.jpg
├── frame_002.jpg
├── frame_003.jpg
├── ...
└── frame_151.jpg
```

各フレームは、
- 空 → 過去フレームまでの累積比較明
- 地上 → 現在フレーム

として生成されます。

### Phase 6 - MP4動画生成
最後にFFmpegを使用してMP4動画を作成します。  
デフォルトでは、
- 24fps
- 1920px幅
- H.264
- yuv420p

で出力します（例: `startrail_24fps.mp4`）。  
151枚の場合、`151 ÷ 24 ≒ 6.29秒` の動画になります。

## 重要な注意事項

### 山マスク検出処理について
現在の山マスク検出処理は、特定の撮影構図・画像サイズ・山の位置を前提としています。  
そのため、撮影場所や構図が大きく異なる画像では、山と空の境界を正しく検出できない可能性があります。

特に、
- 山の位置が大きく異なる
- 地平線が大きく異なる
- 建物や木などの構造物が多い
- 海など、明確な山の境界が存在しない
- カメラの向きが大きく異なる

といった場合には、適切なマスクが生成されない可能性があります。  
`mountain_mask_preview.jpg` は必ず確認してください。問題がある場合は、本番処理を実行しないでください。

### 大量の高解像度JPEGについて
本スクリプトでは、高解像度JPEGをNumPy配列としてメモリ上に読み込みます。  
そのため、画像枚数が多い場合や画像サイズが大きい場合には、大量のメモリを使用する可能性があります。  
特にPhase 2では複数枚の画像を同時にメモリへ読み込むため、搭載メモリが少ない環境では処理に時間がかかったり、メモリ不足になる可能性があります。

### 処理時間について
高解像度画像を大量に処理するため、処理には時間がかかる場合があります。  
特に Phase 2 および Phase 5 では多くの画像処理を行います。処理中にターミナルがしばらく反応しないように見える場合があります。

### 生成された画像について
JPEGは非可逆圧縮形式です。このスクリプトではできるだけ高品質でJPEGを書き出していますが、元画像のRAWデータそのものを保持した処理ではありません。  
より高い画質や色情報を必要とする用途では、RAW/TIFFなどの利用を検討してください。

### 動画について
生成されるMP4は、最終的なタイムラプス動画として扱いやすいようにH.264でエンコードしています。  
現在の設定では1920px幅に縮小しています。元画像の5304px幅をそのまま動画化する場合は、ファイルサイズや処理時間が大きくなるため、別途設定変更が必要です。

### GitHubに写真をアップロードしない
このプロジェクトはプログラムを公開することを目的としており、撮影したJPEG画像をGitHubリポジトリへアップロードすることを想定していません。  
写真には個人情報、撮影場所に関する情報、EXIF情報、著作権上の問題などが含まれる可能性があります。  
写真はリポジトリ外に保存し、必要に応じて `.gitignore` で除外してください。
